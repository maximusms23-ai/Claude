<interfaces>
Plist-Konvention für LaunchAgents (macOS):

- Location: `~/Library/LaunchAgents/` (User-Scope, kein sudo nötig)
- Label MUSS dem Filename ohne `.plist` entsprechen: `com.maxim.tom-compile`
- Validierung via `plutil -lint <file>` muss exit 0 zurückgeben
- Registrierung: `launchctl bootstrap gui/$(id -u) <plist>` (modern, macOS 10.11+)
- Start manuell: `launchctl kickstart gui/$(id -u)/com.maxim.tom-compile` ODER `launchctl start com.maxim.tom-compile`
- Liste: `launchctl list | grep tom-compile`
- Europe/Berlin Schedule 18:00: `StartCalendarInterval` mit `Hour=18, Minute=0` (launchd nutzt lokale Zeitzone des User-Accounts)

WICHTIG — macOS Permission: `launchctl bootstrap` muss von Maxim ausgeführt werden (TCC-Prompt möglich, persistente Berechtigung). Claude darf die Plist schreiben und Smoke-Tests nach Registrierung laufen lassen, aber nicht die initiale `bootstrap` ausführen.
</interfaces>
