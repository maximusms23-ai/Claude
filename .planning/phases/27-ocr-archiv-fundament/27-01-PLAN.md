# Phase 27: OCR-Toolkette + Archiv-Fundament

**Milestone:** v1.4 — Aktive KI + Dokumenten-Fundament
**Requirements:** DOC14-01..06
**Depends on:** Nothing (erste v1.4-Phase)

## Goal

OCR-Stack ist installiert, `archivum/` existiert mit SQLite-FTS5-Schema, `$TOM_VAULT/Archiv/` Symlink zeigt auf `~/Downloads/Archiv/`, und mindestens ein echtes Maxim-PDF ist per Volltext abfragbar.

## Tasks

### Task 1 — Homebrew-Install (DOC14-01)

- `brew install tesseract tesseract-lang ocrmypdf`
- Verifikation: `which tesseract ocrmypdf` liefert Pfade
- `tesseract --list-langs` enthält `deu`

### Task 2 — Vault-Symlink (DOC14-02)

- `ln -sfn "$HOME/Downloads/Archiv" "$TOM_VAULT/Archiv"`
- Verifikation: `test -L "$TOM_VAULT/Archiv"` && `readlink "$TOM_VAULT/Archiv"` zeigt `~/Downloads/Archiv`

### Task 3 — archivum/ Struktur (DOC14-03)

- `mkdir -p /Users/maxim/Claude/archivum/{db,ocr-cache,logs}`
- `README.md` schreiben (Architektur, Usage, Privacy)
- `.gitignore` — DB + cache + logs NICHT in git

### Task 4 — SQLite FTS5 Schema (DOC14-04)

- `archivum/db/archivum.db` via `ocr_pipeline.py --init`
- Tabellen: `documents` (Metadaten) + `documents_fts` (FTS5 Virtual Table, tokenizer `unicode61 remove_diacritics 2`)
- Indizes: `idx_documents_sha256`, `idx_documents_category`
- Verifikation: `sqlite3 archivum/db/archivum.db ".schema documents_fts"` zeigt FTS5-Schema

### Task 5 — ocr_pipeline.py (DOC14-05)

- `archivum/ocr_pipeline.py` mit CLI: `--init`, `--file`, `--category`, `--all`, `--search`
- OCR via `ocrmypdf --language deu --sidecar --skip-text`
- Cache-Layer: `ocr-cache/<sha256>.txt` — idempotent (SHA256-basiert)
- Kategorie-Ableitung aus Parent-Dir im Archiv
- Page-Count via `pdfinfo` (best effort)
- Logging nach `archivum/logs/ocr-pipeline.log`

### Task 6 — Smoke-Test mit echtem PDF (DOC14-06)

- Echtes Maxim-PDF muss in `~/Downloads/Archiv/<kategorie>/` oder `$TOM_VAULT/raw/` liegen (zugänglich ohne TCC-Blocker)
- `python3 archivum/ocr_pipeline.py --file <path>` läuft durch mit Status `ok`
- `python3 archivum/ocr_pipeline.py --search "<keyword>"` liefert Treffer mit Snippet
- Zweiter Run über dieselbe Datei → Status `skip` (Idempotenz verifiziert)
