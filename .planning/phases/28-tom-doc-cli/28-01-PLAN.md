# Phase 28: tom-doc CLI

**Milestone:** v1.4
**Requirements:** TDOC-01..07
**Depends on:** Phase 27 (SQLite FTS5 Schema + OCR-Pipeline existieren)

## Goal

`bin/tom-doc` bietet einen vollständigen CLI-Wrapper (`index`, `search`, `list`, `show`) über den FTS5-Dokumenten-Index und ist in der CLAUDE.md-Wissens-Kaskade verankert.

## Tasks

1. `ocr_pipeline.py` um `list_documents()` + `show_document()` erweitert + `--list` / `--show` CLI-Flags
2. `bin/tom-doc` Bash-Wrapper mit Subcommand-Routing (`index`/`search`/`list`/`show`)
3. Symlink `~/bin/tom-doc → /Users/maxim/Claude/bin/tom-doc`
4. CLAUDE.md Wissens-Kaskade um tom-doc-Pfad erweitert (Punkt 4: Dokumenten-Fragen, Punkt 5 in Wissens-Kaskade-Block)
5. Smoke-Test aller 4 Subcommands

## Success Criteria

1. ✓ `tom-doc --help` zeigt alle 4 Subcommands
2. ✓ `tom-doc search "Arbeitsvertrag"` liefert Treffer mit Snippet
3. ✓ `tom-doc list` zeigt indizierte Dokumente
4. ✓ `tom-doc show 1` zeigt Metadaten + Text-Auszug
5. ✓ `tom-doc index --file <pdf>` ist idempotent (zweiter Lauf → skip)
6. ✓ `~/bin/tom-doc` Symlink existiert
7. ✓ CLAUDE.md erwähnt tom-doc in Wissens-Kaskade

## Out of Scope

- Batch-Index aller 15 Archiv-Kategorien (passiert wenn Maxim Dokumente kopiert)
- Interactive TUI (nicht nötig, CLI reicht)
- JSON-Output-Modus (YAGNI — bei Bedarf später)
