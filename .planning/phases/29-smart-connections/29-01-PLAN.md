# Phase 29: Gemma-in-Obsidian via Smart Connections

**Milestone:** v1.4
**Requirements:** OBPL-01..05
**Depends on:** Nothing (parallel zu Phase 30)

## Goal

Smart Connections Community-Plugin läuft mit Ollama-Backend (`nomic-embed-text` Embeddings + `gemme` Chat), indexiert NUR `90_Wiki/` + `95_Gehirn/knowledge/` dank `.scignore`, und Semantic-Search funktioniert im Editor.

## Tasks

1. Download Plugin-Files v4.3.0 (main.js, manifest.json, styles.css) nach `$TOM_VAULT/.obsidian/plugins/smart-connections/`
2. `.obsidian/community-plugins.json` um `"smart-connections"` erweitert
3. `.scignore` im Vault-Root mit Privacy-Exclude für alle persönlichen Ordner (10_–80_, raw, Clippings, Archiv, Vorlagen)
4. Config-Backup + Activation-Steps nach `.planning/obsidian-plugin-config/smart-connections.json`
5. `CLAUDE.md` Wissens-Kaskade um Punkt 6 "Ad-hoc im Editor → Smart Connections Panel"
6. Maxim aktiviert Plugin in Obsidian UI + konfiguriert Ollama (Embed/Chat Model) — **Handoff-Schritt**

## Split of Responsibility

**Claude autonom:**
- Plugin-Files herunterladen und platzieren
- `community-plugins.json` registrieren
- `.scignore` schreiben
- Config-Backup + Activation-Doku
- CLAUDE.md-Update

**Maxim (Obsidian UI):**
- Plugin-Toggle aktivieren
- Embed Model → Ollama → `nomic-embed-text:latest`
- Chat Model → Ollama → `gemme:latest`
- Initial-Indexing abwarten
- Smoke-Test: Query "TurboQuant" im Smart Connections Panel

Diese Teilung ist explizit — Obsidian-UI-State ist nicht sinnvoll von außen zu manipulieren (data.json-Schema ändert sich zwischen Versionen, Settings-Validation läuft beim Laden im UI).

## Success Criteria

1. ✓ `ls $TOM_VAULT/.obsidian/plugins/smart-connections/` enthält main.js, manifest.json, styles.css
2. ✓ `community-plugins.json` enthält `"smart-connections"`
3. ✓ `.scignore` excludiert alle persönlichen Ordner
4. ✓ Config-Backup in `.planning/obsidian-plugin-config/smart-connections.json` existiert
5. ✓ CLAUDE.md Wissens-Kaskade Punkt 6 dokumentiert
6. ⏳ Maxim aktiviert Plugin + konfiguriert Ollama
7. ⏳ Smoke-Test "TurboQuant" findet `90_Wiki/konzepte/turboquant.md`

Die ersten 5 Kriterien sind **autonom** erledigt. Kriterien 6+7 sind **Handoff an Maxim** und werden per Vermerk in der VERIFICATION.md dokumentiert.

## Fallback

Wenn Smart Connections nicht taugt → Obsidian Copilot als Alternative. Config-Backup-Datei dokumentiert Fallback-Plugin explizit.
