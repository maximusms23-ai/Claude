# Phase 30: Clipper Auto-Enrichment

**Milestone:** v1.4
**Requirements:** CLIP-01..08
**Depends on:** Nothing (parallelisierbar mit Phase 29)

## Goal

`bin/tom-clip-enrich` reichert Obsidian-Clipping-Dateien idempotent an: Summary, Auto-Tags, Konzept-Vorschläge in separater Review-Datei, Wiki-Kategorie-Vorschlag — alles via lokales `gemme`.

## Tasks

1. `tom_tools/clip_enrich.py` — Frontmatter-Parser (minimal, kein PyYAML), gemme-Call mit JSON-Format, Konzept-Queue-Writer
2. `bin/tom-clip-enrich` — Bash-Wrapper nach `tom-wiki`-Schema (uv run)
3. Symlink `~/bin/tom-clip-enrich`
4. Smoke-Test mit `Mannheim – Wikipedia.md`: dry-run + echter Lauf + Idempotenz
5. CLIP-08 Entscheidung treffen (Hook vs launchd vs on-demand)

## Design Decisions

- **Minimaler YAML-Parser** statt PyYAML-Dependency — Obsidian-Frontmatter ist simpel (flat keys + lists), 30 Zeilen Code reichen
- **JSON-Format-Response von gemme** (via `format="json"` in ollama.chat) — strukturiertes Output, einfaches Parsing, temperature=0.3 für Konsistenz
- **Tag-Merge mit Dedup** — existierende Tags bleiben, neue werden angehängt, case-insensitive Dedup
- **Konzepte landen NICHT direkt als Stub-Pages** sondern in `90_Wiki/konzepte-vorschlaege.md` (Review-Queue) — Maxim muss manuell promoten
- **enriched + enriched_at Flags** — idempotent, --force zum Re-Run
- **Body-Preview auf 6000 chars** — Kontext-Budget für gemme (8192 num_ctx)
- **Link/Footnote/Image-Stripping vor LLM-Call** — schlankerer Kontext, bessere Ergebnisse
- **CLIP-08 Entscheidung**: separater on-demand CLI, KEIN Hook in tom-compile-safe. Begründung: Clipper-Enrichment ist opportunistisch, tom-compile täglich — Koppelung bringt keinen Wert. launchd-Job bleibt optional für v1.5.

## Success Criteria

1. ✓ `tom-clip-enrich --help` zeigt Usage
2. ✓ Dry-run über Mannheim-Clipping liefert Summary + Tags + Konzepte + Kategorie ohne Datei-Änderung
3. ✓ Echter Lauf schreibt alle 4 Felder + `enriched: true` + `enriched_at`
4. ✓ `90_Wiki/konzepte-vorschlaege.md` existiert mit Review-Queue-Einträgen
5. ✓ Zweiter Lauf über selbe Datei → `status: skip, reason: already enriched`
6. ✓ Tags-Merge: `clippings` bleibt erhalten, neue Tags werden angehängt, Case-Dedup
7. ✓ Keine offensichtlichen Halluzinationen im Smoke-Test

## Out of Scope (→ v1.5)

- `--watch` Modus (CLIP-06 deferred)
- Batch-Run über alle Clippings
- launchd-Job (optional)
- Tag-Normalisierung gegen existierendes Tag-Vokabular
