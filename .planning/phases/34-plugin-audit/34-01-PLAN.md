# Phase 34: Plugin-Audit + Setup der 17 neuen Plugins

**Milestone:** v1.4.1 — Bridge vor v1.5
**Requirements:** OBPL141-01..05
**Depends on:** Phase 33 (Doku-Routine etabliert, damit Phase 34 selbst die Routine dogfood'et)

## Goal

Die 17 Community-Plugins, die Maxim zwischen v1.4-Close und v1.4.1-Start neu installiert hat, sind vollständig klassifiziert, Tom-relevante Kandidaten haben Config-Backup-Stubs, CLAUDE.md Plugin Landscape ist auf 52 Plugins aktualisiert und die Koexistenz/Integrations-Entscheidungen sind als ADRs dokumentiert.

## Tasks

### Task 1 — Plugin-Metadaten sammeln

- Für jedes der 17 Plugins: `manifest.json` lesen → Name, Version, Autor, Description
- Quelle: `$TOM_VAULT/.obsidian/plugins/<id>/manifest.json`
- Output: Tabelle in `plugin-audit-v1.4.1.md`

### Task 2 — Klassifikation + Empfehlung (OBPL141-01)

- 4 Kategorien: ★ Tom-relevant / ~ Orthogonal / · Nicht relevant / ⚠ Potentiell störend
- Pro Plugin: Klassifikation + Empfehlung + Begründung
- Summary-Block nach Klassifikation
- Offene Fragen an Maxim

### Task 3 — Config-Backup-Stubs (OBPL141-02)

- Für Setup-Kandidaten (`eml-reader`, `obsidian-apple-reminders-plugin`): JSON-Stub nach `smart-connections.json`-Pattern
- Felder: `_meta`, `plugin_id`, `privacy_assessment`, `recommended_settings`, `activation_steps`, `tom_integration`, `next_review`
- Status: `prepared-pending-maxim-activation`

### Task 4 — ADR-003 (OBPL141-04)

- `obsidian-ocr` Koexistenz mit `tom-doc`
- Schreibgrenze: `obsidian-ocr` darf NICHT in `archivum/` schreiben
- Rollen-Teilung: tom-doc = Batch + FTS5, obsidian-ocr = Ad-hoc-Editor

### Task 5 — ADR-004 (OBPL141-05)

- `mcp-tools` als v1.5-Integrationskandidat
- Begründung: MCP ist jung, Integration braucht Phase nicht Commit, Privacy-kritisch
- 6 Arbeitsschritte für v1.5-Phase dokumentiert

### Task 6 — CLAUDE.md Plugin Landscape Update (OBPL141-03)

- Gesamtzahl 35 → **52** (nicht 53 wie im Plan — tatsächliche Zählung)
- Tom-relevant Tabelle um 4 v1.4.1-Einträge erweitert
- Neue Kategorie "LLM-Alternativen (installed-but-unused)"
- Neue Kategorie "Email / Messaging"
- Neue Warning-Box `obsidian-ocr` vs `tom-doc`
- Neue Empfehlungs-Box `mcp-tools`
- Referenzen um ADR-003, ADR-004, plugin-audit-v1.4.1.md erweitert
