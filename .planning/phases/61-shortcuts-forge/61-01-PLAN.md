## Kernentscheidungen

| Entscheidung | Warum |
|---|---|
| Symlink `~/Documents/Tom-Shortcuts/helpers` → Repo | iCloud evakuiert Kopien, nie den Symlink; Ziel außerhalb iCloud; kein Deploy-Drift. Fallback `--copy` (rsync) |
| `tidy` statt Plugin-Patch | Plugin bleibt update-fähig; idempotente Nachsortierung Wurzel→`signed/`+`archive/` |
| Env-Var statt userConfig-Write | userConfig-Format unbekannt/leer; `CLAUDE_PLUGIN_OPTION_OUTPUT_DIR` in settings.json-env + CLI-Export ist doppelt abgesichert |
| Cherri documented-only | Phase eng halten; `--engine cherri` als Deferred |

## Risiken + Fallbacks

| Risiko | Gegenmaßnahme |
|---|---|
| Slash-Command in `claude --print` greift nicht | Plain-Prompt-Fallback (`--fallback-prompt`), Artefakt-Check als harte Wahrheit |
| Permission-Block beim Sign-Call | `--permission-mode acceptEdits` + allowedTools; konkrete Allowlist-Permission nachziehen |
| iCloud-Eviction | Symlink; `--copy`-Fallback dokumentiert |
| Shortcuts blockt Shell-Skripte | Manuelle Vorbedingung (Einstellungen → Erweitert) + Doctor-Hinweis |
| Build aus laufender Session | CLI-Warnung + Session-Regel in Doku |
