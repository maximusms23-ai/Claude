# Kontakte

Externe Ansprechpartner: Ärzte, Ämter, Handwerker, Versicherungsvertreter, Anwälte, Nachbarn, Schulen/Kitas.

## Struktur

Jeder Kontakt bekommt eine eigene Datei mit Frontmatter:

```yaml
---
title: Dr. Max Mustermann
type: kontakt
kategorie: arzt  # arzt, amt, handwerker, anwalt, versicherung, schule, sonstiges
created: YYYY-MM-DD
tags: [kontakte, arzt]
---
```
