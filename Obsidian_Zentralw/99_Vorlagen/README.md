# Vorlagen

Templates für wiederkehrende Einträge im Vault. Nutzung:

1. **Manuell**: Inhalt kopieren, neue Datei an Zielort anlegen, Platzhalter füllen.
2. **Templater-Plugin** (optional, v1.1): Platzhalter `{{ name }}`, `{{ date }}` werden automatisch ersetzt.

## Verfügbare Templates

- [[Person]] — neue Person (Familie, Kontakt)
- [[Dokument]] — einzelnes Dokument mit Metadaten
- [[Termin]] — allgemeiner Termin
- [[Arzttermin]] — spezialisiert für medizinische Termine
- [[Projekt]] — neues Vorhaben (in `30_Projekte/`)
- [[Vertrag]] — Versicherung / Dienstleister
- [[Social-Post]] — Social-Media-Post (in `80_Social_Media/`)
- [[Hardware-Geraet]] — Hardware-Inventar (in `70_Hardware/`)
- [[Quelle]] — Wiki-Quelle (in `90_Wiki/quellen/`)
