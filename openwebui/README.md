# Open WebUI — Referenz (Repo)

Optional: lokale Chat-Oberfläche über Ollama. Dieses Verzeichnis enthält nur **Beispiel-Env** für einen Clone — keine Laufzeit-Container hier.

## Setup-Skizze

1. Open WebUI nach Herstelleranleitung installieren (Docker oder nativ).
2. `cp .env.example .env` und Werte setzen (mindestens `OLLAMA_BASE_URL`).
3. Ollama: `ollama serve` auf Port 11434.

## Tom-Hinweis

Toms primäre Oberflächen sind **Obsidian**, **Tom-CLI** (`bin/tom-*`) und optional **OpenClaw** — Open WebUI ist **optional** und nicht Teil der Pflicht-Workflows.
